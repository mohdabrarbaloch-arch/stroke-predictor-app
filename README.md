# 🧠 Stroke Prediction App

A Machine Learning web application that predicts stroke risk based on patient health data.

## 🚀 Live Demo
**[Visit the App](https://stroke-predictor-app.streamlit.app)**

## 📊 Features
- Real-time stroke risk prediction
- Interactive patient input form
- Powered by pre-trained ML pipeline
- Built with Streamlit for seamless deployment

## 🧠 Model Info
- **Algorithm:** Pre-trained ML Pipeline
- **Dataset:** Healthcare Stroke Dataset (5,000+ patients)
- **Features:** Age, Gender, BMI, Glucose Level, Hypertension, Heart Disease, Work Type, Smoking Status, etc.

## 🛠️ Tech Stack
- Python
- Streamlit
- Scikit-learn
- Pandas
- Joblib

## 📦 How to Run Locally
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

